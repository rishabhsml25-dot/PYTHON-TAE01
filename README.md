# PYTHON-TAE01 - Typing Tester

Python Typing Tester project developed in phases.

## Files

### Phase 1 - 50% — `phase 1.py`
Basic typing test with:
- Predefined sentence
- Timer
- WPM calculation
- Basic character accuracy
- Correct character count
- Performance feedback
- Retry option

### Phase 2 - 70% — `phase 2.py`
Improved typing test with:
- Random sentence on every attempt
- Timer
- WPM calculation
- Words typed
- Correct words
- Wrong words
- Correct characters
- Wrong characters
- Accuracy percentage
- Performance feedback
- Retry option

## How to Run

Phase 1:

```bash
python "phase 1.py"
```

Phase 2:

```bash
python "phase 2.py"
```
