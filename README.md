# PYTHON-TAE01 - Typing Tester

This repository contains the Python Typing Tester project developed in phases.

## Files

### Phase 1 - 50% — `phase 1.py`
Basic typing test:
- Predefined sentence
- Timer
- Typed input
- Time taken
- WPM
- Accuracy
- Correct character count
- Performance feedback
- Retry option

### Phase 2 - 70% — `phase 2.py`
Improved version:
- All main features from Phase 1
- Words typed
- Correct characters
- Wrong characters
- Accuracy percentage
- WPM
- Performance feedback
- Retry option

### Phase 3 - 100%
Planned final improvements:
- Multiple text levels
- Attempt history
- Best score
- Final performance summary

## How to Run

For Phase 1:

```bash
python "phase 1.py"
```

For Phase 2:

```bash
python "phase 2.py"
```
